# Maquina-V5 Cloud Gaming

## Objetivo
Crear una plataforma personal de cloud gaming que pueda controlarse desde Android.

## Funciones previstas
- Encender y apagar una máquina remota cuando el proveedor lo permita.
- Mostrar el estado de la máquina.
- Conectar al escritorio de juego mediante streaming.
- Transmitir vídeo, audio y controles.
- Conservar partidas y configuraciones.
- Permitir reconexión tras interrupciones.

## Plan de desarrollo
1. Investigar opciones de GPU remota y sus condiciones de uso.
2. Verificar el funcionamiento del servidor de juegos.
3. Configurar el streaming remoto.
4. Crear una aplicación Android para administrar la conexión.
5. Probar estabilidad, rendimiento y persistencia.
6. Evaluar clientes para Android TV, Windows y Roku.

## Restricciones
- No depender de sesiones gratuitas ilimitadas que no estén garantizadas.
- No ejecutar binarios sin revisar su procedencia y seguridad.
- No modificar el proyecto original.
- Mantener las credenciales fuera del repositorio.
