# Maquina-V5 Android App

Aplicación Android para administrar una máquina remota de cloud gaming.

## Funciones previstas

- Mostrar el estado del servidor remoto.
- Conectar con la máquina de juegos.
- Iniciar el streaming mediante un cliente compatible.
- Permitir desconectar de forma segura.
- Guardar las preferencias de calidad y controles.

## Arquitectura

La aplicación Android será independiente del servidor remoto.

El servidor deberá ejecutarse en una infraestructura compatible con GPU y con las condiciones de uso de su proveedor.
